Changelog — V1 through V5
Changelog
Technique Reference
Every meaningful change from the original V1 file to V5, and the specific reason each one was made.
V1— original file
—
2 modes via dropdown. Fixed bluntness. Output locked in <pre>. No history, no export.
—
No technique selection — AI defaults to whatever its training bias prefers for every task.
V2— architecture overhaul
◆
6 mode cards with distinct workflow logic. Bluntness slider. Persona + audience injection. Feature toggles. Editable output. Download. localStorage history.
V3— meta-cognition layer
★
Meta-cognitive framework selection — AI classifies the problem and selects a reasoning mode with justification before responding.
V4— dynamic technique stack
★
All manual technique toggles removed. AI self-selects a 3-layer stack (PRIMARY / SECONDARY / VERIFY) based on the brief. Conflict detection built in. All 5 prompt structure diffs applied.
V5— this version
★
Bluntness now threads through the entire prompt — not just the anti-sycophancy rule. At level 4–5, the devil's advocate instructions change, the assumption audit changes, and the CoVe threshold tightens. Level 1 and 5 produce structurally different prompts.
★
Pushback protocol block — tells the AI to defend its technique selection and output with evidence, and to state explicitly whether it's adjusting or holding its position. Prevents silent capitulation to user pushback.
★
Negative space instruction — explicit DO NOT PRODUCE list: no hedging language, no end-of-section summaries, no motivational framing, no unsolicited alternatives.
★
CoVe action rules completed — all 4 confidence levels now have explicit instructions. SPECULATIVE: flag to user or rewrite. LIKELY: include with explicit hedge. UNKNOWN: remove entirely. Bluntness level adjusts which threshold triggers removal.
★
Expertise level selector — Novice / Intermediate / Advanced / Expert. Controls how much the AI explains vs. assumes, whether it defines domain terms, and whether it focuses on basics or edge cases.
★
Output length selector — Brief (<300w), Detailed, Full Coverage. Injected into every generated prompt so response length is explicit and consistent.
★
3 additional stack conflict rules — Socratic + MECE, Step-Back + First Principles, Analogical + First Principles. All three pairs are now flagged as incompatible with explanations.
★
Live brief quality scorer — analyses your raw idea in real time and signals which of 5 quality markers are present (length, audience, constraints, goal, specifics). Helps you improve the input before generating.
★
History search — instant filter across all saved prompts by mode name or idea text.
★
Ctrl+Enter to generate — keyboard shortcut.
The AI selects from these and builds a PRIMARY / SECONDARY / VERIFY stack based on your brief. It must declare its choices, execution order, and ruled-out conflicts in its first reply.
